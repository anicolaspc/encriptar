# 🔐 Encriptador de Texto

Este es un encriptador de texto simple, desarrollado como parte del **Challenge del curso de Desarrollo Frontend de Alura LATAM** en el programa **Oracle Next Education (ONE) – Grupo 7**.

🔗 **Sitio en vivo:**  
[https://anicolaspc.github.io/encriptar/](https://anicolaspc.github.io/encriptar/)

---

## 💡 Descripción

El objetivo del proyecto es permitir a los usuarios:

- ✏️ Ingresar un texto en minúsculas y sin acentos.
- 🔐 Encriptar el texto reemplazando vocales por cadenas específicas.
- 🔓 Desencriptar el texto en cualquier momento.
- 📋 Copiar el resultado en el portapapeles.

> Este proyecto refuerza conceptos fundamentales como manipulación del DOM, validación de datos, lógica condicional y diseño responsive.

---

## 🧪 Reglas de encriptación

| Letra | Reemplazo |
|-------|-----------|
| a     | ai        |
| e     | enter     |
| i     | imes      |
| o     | ober      |
| u     | ufat      |

**Ejemplo**  
Texto original: `gato`  
Texto encriptado: `gaitober`
